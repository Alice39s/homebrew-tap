# Alice39s/homebrew-tap

Homebrew formulae for [xmtr](https://github.com/Alice39s/xmtr), a concurrent traceroute that maps every hop on [xmsl.dev IPMap](https://xmsl.dev/ipmap).

```sh
brew install alice39s/tap/xmtr
```

The formula installs the release binary for macOS (Apple silicon and Intel) and Linux (x86_64 and ARM64). The xmtr release workflow updates it on every release.
